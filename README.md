# Theodora Field Guide

An unofficial, spoiler-filtered recruitment and support reference for Theodora's initial route in Fire Emblem: Fortune's Weave.

The static website lives in `site/`. It uses only the curated early-route roster; major later-story characters and story unlock explanations are excluded. Character portraits and game names belong to their respective rights holders. Community-sourced data is not independently verified in-game; source links and limitations appear inside the guide.

Personal wishlist/recruitment progress stays in the current browser. There are no accounts or cloud synchronization.

## Deployment

GitHub Pages serves the root of the `gh-pages` branch, published from `site/`. No third-party runtime packages are required.
